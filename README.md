# The Executive AI Readiness Diagnostic

A single-page interactive diagnostic that takes an executive through eight decisions and scores their organisation against the GenAI Divide — distinguishing the **5%** of pilots producing measurable P&L impact from the **95%** that don’t.

Companion to *AI for the Executive Worker: A Sovereign Framework for Cross-Sector Leadership in the Age of Artificial Intelligence* (Workshop Edition, 2026) by **Dr. Rohan Jowallah**.

## What it does

Eight steps:

1. **Setup** — Organisation, sector, role, candidate AI initiative.
2. **Strategic Frame** — Buy / Partner / Build, Sovereign AI principles, P&L target.
3. **CARE** — Strategic decision frame: Consider · Analyse · Reflect · Evaluate.
4. **CRAFT** — AI architecture: Context · Role · Action · Format · Threshold.
5. **ACRE** — Output assurance: Accuracy · Completeness · Relevance · Equity.
6. **CALF / SECAS** — Institutional readiness diagnostic across 9 dimensions.
7. **Governance Wheel** — 8-domain Sovereign AI governance audit.
8. **Diagnostic** — 0–100 score, GenAI Divide verdict, copyable board brief, 90-day roadmap.

## Frameworks

- **CARE** — Consider, Analyse, Reflect, Evaluate
- **CRAFT** — Context, Role, Action, Format, Threshold
- **ACRE** — Accuracy, Completeness, Relevance, Equity
- **CALF** — Capacity, Adoption, Literacy, Fluency (foundation)
- **SECAS** — Strategy, Ethics, Capability, Accountability, Sustainability (governance overlay)
- **Jowallah Governance Wheel** — Strategy alignment · Data · Procurement · Workforce · Output · Equity · Risk · Public accountability

Anchored in MIT NANDA’s *GenAI Divide* research, the NIST AI Risk Management Framework, McKinsey 7S, Kotter’s 8-Step Change Model, and Yale SOM’s CELI work.

## Design

- **Caribbean palette** — deep sea blue, palm green, sunshine, Trinidad coral
- **WCAG AA+ contrast** — body text reaches 19:1, 4px focus rings on all interactive elements
- **Keyboard-first** — skip-link, semantic landmarks, ARIA, prefers-reduced-motion respected
- **Single file** — pure HTML + React via Babel-standalone CDN. No build step.

## Deploy

Static site — drop \`index.html\` on any static host. Live at GitHub Pages once enabled.
